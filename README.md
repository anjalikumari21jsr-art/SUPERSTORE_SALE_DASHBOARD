Super Sales Dashboard 📊
Overview

The Super Sales Dashboard is an interactive Power BI project designed to analyze sales performance, customer behaviour, and business profitability. It transforms raw sales data into meaningful visual insights, helping businesses make data-driven decisions.

The dashboard provides an easy-to-understand overview of sales trends, regional performance, product categories, shipping analysis, and profit distribution.

Features
📈 Interactive Sales Dashboard
🌍 Region-wise Sales Analysis
📦 Category & Sub-Category Performance
💰 Profit and Revenue Tracking
👥 Customer Segment Analysis
🚚 Shipping Mode Analysis
📅 Monthly & Yearly Sales Trends
🎯 Dynamic Filters and Slicers
📊 KPI Cards for Quick Insights
📍 State-wise Sales Visualization
Dashboard Insights

The dashboard helps answer questions such as:

Which region generates the highest sales?
Which product category is the most profitable?
Which customer segment contributes the most revenue?
How do monthly sales trends change over time?
Which shipping mode is most frequently used?
Which states have the highest sales and profit?
